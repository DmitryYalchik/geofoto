# ГеоФото

Бесплатная камера для iPhone: на каждое фото добавляются дата, время, координаты и читаемый адрес.

**Открыть:** https://dmitryyalchik.github.io/geofoto/

## Установка на iPhone

Откройте ссылку в Safari, нажмите «Поделиться» → «На экран «Домой»». При первом запуске разрешите доступ к геопозиции и камере.

## Как пользоваться

**Новое нарушение** — пошагово, каждый шаг на одном экране, «‹ Назад» возвращает без потери данных:

1. **Что нарушено?** — парковка на тротуаре, на газоне, под знаком «Остановка запрещена», на пешеходном переходе или своё описание.
2. **Снимки** — снимите общий план, госномер и знак. Нажмите на плитку, чтобы открыть снимок: внизу лента превью для перехода между снимками (или свайп), любой снимок можно удалить.
3. **Автомобиль** — госномер и марка с моделью, вводятся после съёмки, чтобы их можно было рассмотреть на фото. Для марки есть подсказки: можно писать по-русски («тойота кам» → Toyota Camry) или сразу модель («rio» → Kia Rio); недавно введённые марки показываются первыми.
4. **Итог** — «Сохранить в Фото» сохраняет все снимки сразу с номерами «1 из 3» … «3 из 3», «Текст жалобы» собирает готовый текст (его можно поправить), «📤 Подать» копирует текст и открывает приложение «Госуслуги. Решаем вместе» (если его нет — App Store; есть и ссылка на сайт) — там остаётся нажать «Написать», вставить текст и прикрепить снимки из галереи, «Следующее ТС» начинает снимки другой машины с тем же нарушением и адресом. Если карта определила адрес неточно, его можно исправить кнопкой «✎ Изменить» — исправленный адрес попадёт на все снимки серии и в жалобу.

**Просто фото с координатами** — снимки без нарушения и госномера.

**Камера** (⚙︎ Настройки): системная — максимальное качество; встроенная — живой видоискатель с координатами и направлением, снимки подряд без выхода из приложения.

**Госномер**: при переходе к шагу «Автомобиль» приложение пытается само найти номер на снимках. Если в кадре несколько номеров, приложение предложит выбрать нужный. Точнее — кнопкой «🔍 Выделить номер на снимке»: обведите номер пальцем, он распознается, а его увеличенная копия может появиться в подписи снимков (переключатель «Крупный номер в подписи»). Распознавание работает на телефоне, модуль загружается при первом использовании; результат нужно проверять.

**Время по интернету**: приложение сверяет часы телефона с сервером; на главном экране видно, точные ли часы, а в подписи рядом со временем телефона стоит время по интернету.

Под каждым снимком — чёрная полоса с мелким текстом, как на фото с камер фиксации: дата и время, координаты, точность, высота, направление съёмки по компасу, адрес, госномер, марка и модель, нарушение. Координаты и дата также записываются в EXIF, поэтому «Фото» показывает снимок на карте.

Адреса берутся из OpenStreetMap (Nominatim), для них нужен интернет. В настройках (⚙︎) можно включить почтовый адрес с индексом и районом.

## Свои нарушения и шаблон жалобы

В ⚙︎ Настройки → «✏️ Кнопки нарушений» можно изменить, добавить, удалить и переставить кнопки нарушений: у каждой есть значок, название (оно пишется на снимке) и текст для жалобы.

В ⚙︎ Настройки → «📝 Шаблон текста жалобы» можно переписать текст жалобы. Метки `{дата}`, `{время}`, `{место}`, `{адрес}`, `{координаты}`, `{марка}`, `{номер}`, `{нарушение}`, `{снимков}` заменяются данными снимков; ниже показывается пример.

## Если нет доступа к геопозиции

Настройки → Конфиденциальность и безопасность → Службы геолокации → Сайты Safari → «При использовании». Также Настройки → Приложения → Safari → Геопозиция → «Спрашивать».

## Версия и обновления

Под кнопками главного экрана мелко указаны дата обновления и хеш коммита. Приложение само проверяет обновления при запуске и при возврате в него; если вышла новая версия, на главном экране появляется кнопка «⟳ Вышла новая версия — обновить». Проверить вручную можно в ⚙︎ Настройки → «Проверить обновления». Хеш и дату подставляет сборка GitHub Actions при публикации.
