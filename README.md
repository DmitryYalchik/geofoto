# ГеоФото

Бесплатная камера для iPhone: на каждое фото добавляются дата, время, координаты и читаемый адрес. Работает как веб-приложение (PWA), без App Store, Mac и аккаунта разработчика.

**Открыть:** https://dmitryyalchik.github.io/geofoto/

## Установка на iPhone

Откройте ссылку в Safari, нажмите «Поделиться» → «На экран «Домой»». При первом запуске разрешите доступ к геопозиции и камере.

## Возможности

Съёмка родной камерой iPhone в полном качестве. Под фото добавляется чёрная полоса с мелким текстом, как на фото с камер фиксации: дата и время, координаты, точность, высота, направление съёмки по компасу, адрес и ваш комментарий (например, госномер и описание нарушения). Компас на iPhone включается кнопкой «Включить компас». Координаты и дата также записываются в EXIF, поэтому «Фото» показывает снимок на карте. Сохранение в галерею: «Сохранить» → «Сохранить изображение».

Адреса берутся из OpenStreetMap (Nominatim), для них нужен интернет. Без сети на фото будут только координаты и время.

## Если нет доступа к геопозиции

Настройки → Конфиденциальность и безопасность → Службы геолокации → Сайты Safari → «При использовании». Также Настройки → Приложения → Safari → Геопозиция → «Спрашивать».
