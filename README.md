# ГеоФото

Бесплатная камера для iPhone: на каждое фото добавляются дата, время, координаты и читаемый адрес.

**Открыть:** https://dmitryyalchik.github.io/geofoto/

## Установка на iPhone

Откройте ссылку в Safari, нажмите «Поделиться» → «На экран «Домой»». При первом запуске разрешите доступ к геопозиции и камере.

## Возможности

Съёмка родной камерой iPhone в полном качестве. Под фото добавляется чёрная полоса с мелким текстом, как на фото с камер фиксации: дата и время, координаты, точность, высота, направление съёмки по компасу, адрес, госномер и нарушение или комментарий. Компас на iPhone включается кнопкой «Включить компас». Координаты и дата также записываются в EXIF, поэтому «Фото» показывает снимок на карте. Сохранение в галерею: «Сохранить» → «Сохранить изображение».

Адреса берутся из OpenStreetMap (Nominatim), для них нужен интернет. Без сети на фото будут только координаты и время.

## Для жалоб на нарушения

**Госномер** — отдельное поле, буквы автоматически становятся заглавными, латиница заменяется на кириллицу (A → А), номер форматируется как «А123ВВ 777».

**Быстрые кнопки нарушений** — «Парковка на тротуаре», «На газоне», «Под знаком „Остановка запрещена“», «На пешеходном переходе» подставляют текст в поле нарушения.

**Серия снимков** — нажимайте «Ещё фото», чтобы добавить снимки одного нарушения (общий план, номер, знак). При сохранении они получат номера «1 из 3», «2 из 3», «3 из 3» и сохранятся все сразу. Лишний снимок можно удалить.

**Текст жалобы** — кнопка на экране снимка собирает готовый текст: дата, время, адрес, координаты, госномер и нарушение. Текст можно поправить и скопировать в форму Госуслуг или ГИБДД.

**Почтовый адрес** — в настройках можно включить адрес с индексом и районом: «125009, г. Москва, Тверской район, Театральная площадь, д. 1».

## Если нет доступа к геопозиции

Настройки → Конфиденциальность и безопасность → Службы геолокации → Сайты Safari → «При использовании». Также Настройки → Приложения → Safari → Геопозиция → «Спрашивать».

## Версия

Под кнопкой «Сфотографировать» мелко указаны дата обновления и хеш коммита — по ним видно, загрузилась ли новая версия. Их подставляет сборка GitHub Actions при публикации.
