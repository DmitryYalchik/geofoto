# ГеоФото

Бесплатная камера для iPhone: на каждое фото добавляются дата, время, координаты и читаемый адрес.

**Открыть:** https://dmitryyalchik.github.io/geofoto/

## Установка на iPhone

Откройте ссылку в Safari, нажмите «Поделиться» → «На экран «Домой»». При первом запуске разрешите доступ к геопозиции и камере.

## Как пользоваться

**Новое нарушение** — пошагово, каждый шаг на одном экране, «‹ Назад» возвращает без потери данных:

1. **Что нарушено?** — парковка на тротуаре, на газоне, под знаком «Остановка запрещена», на пешеходном переходе или своё описание.
2. **Снимки** — снимите общий план, госномер и знак. Нажмите на плитку, чтобы открыть снимок: внизу лента превью для перехода между снимками (или свайп), любой снимок можно удалить.
3. **Госномер** — вводится после съёмки, чтобы его можно было рассмотреть на фото. Латиница заменяется на кириллицу.
4. **Итог** — «Сохранить в Фото» сохраняет все снимки сразу с номерами «1 из 3» … «3 из 3», «Текст жалобы» собирает готовый текст для Госуслуг или ГИБДД, «Следующее ТС» начинает снимки другой машины с тем же нарушением.

**Просто фото с координатами** — снимки без нарушения и госномера.

Под каждым снимком — чёрная полоса с мелким текстом, как на фото с камер фиксации: дата и время, координаты, точность, высота, направление съёмки по компасу, адрес, госномер и нарушение. Координаты и дата также записываются в EXIF, поэтому «Фото» показывает снимок на карте.

Адреса берутся из OpenStreetMap (Nominatim), для них нужен интернет. В настройках (⚙︎) можно включить почтовый адрес с индексом и районом.

## Если нет доступа к геопозиции

Настройки → Конфиденциальность и безопасность → Службы геолокации → Сайты Safari → «При использовании». Также Настройки → Приложения → Safari → Геопозиция → «Спрашивать».

## Версия

Под кнопкой «Сфотографировать» мелко указаны дата обновления и хеш коммита — по ним видно, загрузилась ли новая версия. Их подставляет сборка GitHub Actions при публикации.
